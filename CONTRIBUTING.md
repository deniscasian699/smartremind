# 🤝 Contributing to SmartRemind

Thank you for your interest in improving SmartRemind.

</div>

---

SmartRemind is proprietary software. This public repository is intended for documentation, legal transparency, issue tracking and feature discussion. Direct source-code contributions are not accepted unless the developer explicitly requests them.

## Report a Bug

Use the [bug report template](../../issues/new?template=bug_report.md) and include:

- Device model and Android version
- SmartRemind version
- Clear steps to reproduce
- Expected and actual behavior
- Screenshots or recordings when helpful

You may also report issues at [bugs.deniscasian.com](https://bugs.deniscasian.com/).

## Suggest a Feature

Open a [feature request](../../issues/new?template=feature_request.md). Explain the problem, proposed behavior, alternatives and who would benefit.

## Documentation Corrections

Pull requests may be used for clear documentation corrections. Do not submit proprietary app source code, reverse-engineered material, secrets, store credentials or copyrighted third-party assets.

## Guidelines

- Search existing issues first.
- Use descriptive titles and one issue per topic.
- Remove personal, payment and security-sensitive information.
- Be respectful and constructive.
- Report vulnerabilities privately under [SECURITY.md](./SECURITY.md).

## Support Development

A positive Google Play review or an optional in-app Supporter purchase helps independent development.

Thank you for supporting SmartRemind.
